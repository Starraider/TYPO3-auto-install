# Test Script Analysis and Categorization

## Analysis Summary

This document summarizes the analysis of existing bash scripts in the workspace and their categorization for the new test directory structure.

## Script Inventory and Categories

### Core Installation Scripts (Remain in Root)
- `install-typo3.sh` - Main TYPO3 installation script with replacement functions
- `create-sitepackage.sh` - Sitepackage creation and customization script

### Unit Tests → `tests/unit/`
- `test_replacement_units.sh` - Tests individual replacement function components in isolation
- `test_simple_permissions.sh` - Simple permission preservation tests

### Integration Tests → `tests/integration/`
- `test_real_sitepackage.sh` - Tests actual sitepackage replacement with real template
- `test_permission_preservation.sh` - Tests file permission and structure preservation functionality

### Compatibility Tests → `tests/compatibility/`
- `test_bash_compatibility.sh` - Cross-platform bash compatibility test suite
- `test_bash_version_compatibility.sh` - Bash version-specific compatibility tests
- `run_all_compatibility_tests.sh` - Comprehensive compatibility test runner

### Error Handling Tests → `tests/error-handling/`
- `test_replacement_error_handling.sh` - Error handling and recovery mechanism tests

### Development Utilities → `tests/development/`
- `debug_validation.sh` - Debug validation function specifically
- `debug_hyphen_test.sh` - Debug script for hyphenated project names
- `test_replacement_quick.sh` - Quick test runner for development feedback
- `extract_replacement_functions.sh` - Extracts replacement functions for testing

### Test Data → `tests/fixtures/`
- `test_permission_preservation/` directory (including `executable_script.sh`)
- `test_error_handling/` directory with various test scenarios
- `test_results/` → `tests/reports/test_results/`

## Scripts Identified for Removal

### Obsolete Scripts
- `replacement_functions_only.sh` - Generated file that can be recreated by extract script
- `run_all_replacement_tests.sh` - Will be replaced by new master test runner

### Rationale for Removal
1. **replacement_functions_only.sh**: This is a generated file created by `extract_replacement_functions.sh`. It should not be committed to version control as it can be regenerated as needed.

2. **run_all_replacement_tests.sh**: This script will be superseded by the new master test runner (`tests/run-tests.sh`) that provides better organization and category-based execution.

## Dependencies Identified

### Cross-Script Dependencies
- Most test scripts depend on `replacement_functions_only.sh` (generated by extract script)
- Test scripts reference `install-typo3.sh` for function extraction
- Compatibility tests have internal cross-references
- Error handling tests depend on test data in `test_error_handling/` directory

### Path References to Update
- All test scripts will need path resolution functions to locate project root
- References to test data directories need updating for new fixture locations
- Cross-references between test scripts need updating for new directory structure
